# My App Store – iOS 6 Starter

This is a starter catalogue for a custom App Store project.

## What this file does
- Provides an app catalogue (`catalog/apps.json`)
- Provides an iOS 6-inspired web interface (`web/index.html`)
- Lets you add your own app download entries

## Important
This ZIP is NOT an iOS firmware file and does not install itself on an iPod.
An actual iOS 6 app requires an iOS-compatible IPA or, on an appropriately configured device,
a compatible package/installation method.

Do not upload Apple firmware files to this project unless you have the legal right to distribute them.

## Add an app
Edit `catalog/apps.json` and add your app's name, version, description and download URL.
